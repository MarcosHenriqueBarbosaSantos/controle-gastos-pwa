Você pediu para criar uma senha nova. Digite este código no app:

{{ .Token }}

Ou, se preferir, toque no botão abaixo e escolha a senha nova na página que abrir.

Criar senha nova

O código e o botão valem por 1 hora e só podem ser usados uma vez. Se você pedir outro e-mail, este deixa de valer. Se não foi você quem pediu, é só ignorar esta mensagem: a sua senha continua a mesma.
